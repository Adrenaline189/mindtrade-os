📘 คู่มือการกรอกค่า (Dashboard Guide)

วิธีใช้งานแบบเร็ว
  • 1) ตั้ง Leverage และ Leverage by symbol ให้ตรงตามต้องการ
  • 2) ตั้ง Risk / Trade ต่ำ ๆ ก่อนเริ่ม (เช่น 0.005 = 0.5%)
  • 3) กด Save ก่อน แล้วค่อยกด START
  • 4) ถ้าต้องการหยุดทันที ใช้ปุ่ม PANIC
ความหมายแต่ละช่อง
  • RSI MIN / RSI MAX: ช่วง RSI ที่ระบบยอมรับสำหรับเข้าเทรด
  • Golden Zone %: ระยะย่อที่ยอมรับจากจุดอ้างอิง (ยิ่งน้อยยิ่งเข้ม)
  • Risk / Trade: ความเสี่ยงต่อไม้ (0.01 = 1% ต่อไม้)
  • Leverage (x): เลเวอเรจเริ่มต้นสำหรับทุกเหรียญ
  • Margin Mode: cross = แชร์มาร์จิ้นทั้งพอร์ต, isolated = แยกต่อเหรียญ
  • Leverage by symbol: ตั้งแยกรายเหรียญ เช่น BTC/USDT:5,ETH/USDT:3 (ถ้ามี จะทับค่า Leverage ด้านบน)
  • Max trades/day: จำกัดจำนวนไม้ต่อวัน
  • Cooldown minutes: เวลาพักก่อนเข้าไม้ใหม่
  • Daily loss cap %: ขาดทุนรวมต่อวันสูงสุดก่อนระบบกันเทรด
  • Symbols: รายชื่อเหรียญที่ให้ระบบวิ่ง คั่นด้วยคอมม่า
ค่าแนะนำเริ่มต้น (Safe)
  • Risk / Trade: 0.005
  • Leverage: 3-5x
  • Max trades/day: 2-3
  • Cooldown: 90-180 นาที
  • Daily loss cap: 1.5-2.5%
