เป้าหมาย: ตั้งค่าให้พร้อมเริ่มใช้งานได้ภายใน 5-10 นาที

Step 1) เตรียมบัญชี Binance

  • เปิดบัญชี Futures ให้พร้อม
  • เปิด 2FA ก่อนสร้าง API Key

Step 2) สร้าง API Key

  • ไปที่ API Management
  • คัดลอก API Key + Secret (แสดงครั้งเดียว)

Step 3) ตั้งสิทธิ์

  • Enable Reading: ON
  • Enable Futures: ON
  • Withdraw: OFF

Step 4) IP Whitelist

ถ้าเปิด IP restriction ให้เพิ่ม IP ของเซิร์ฟเวอร์:

{{ vps_ip }}

Step 5) บันทึกในระบบ

  • กรอก API ในหน้า Dashboard
  • กด Test Connection
  • ตรวจสอบ /api/connection
