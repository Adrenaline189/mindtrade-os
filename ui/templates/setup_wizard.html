🧭 MindTrade OS - Setup Wizard (Binance API)

เป้าหมาย: ตั้งค่าให้ลูกค้าเริ่มใช้งานได้ง่ายที่สุด ภายใน 5-10 นาที

Step 1) เตรียมบัญชี Binance

  • ล็อกอิน Binance และเปิดใช้งานบัญชี Futures ให้เรียบร้อย
  • เปิด 2FA ก่อนสร้าง API Key

Step 2) สร้าง API Key

  • ไปที่ API Management แล้วสร้าง API ใหม่
  • คัดลอก API Key และ Secret Key (secret จะเห็นครั้งเดียว)

Step 3) ตั้งสิทธิ์ให้ถูก

  • Enable Reading: ON
  • Enable Futures: ON (ถ้าใช้งาน futures)
  • Withdraw permission: OFF เสมอ

Step 4) IP Whitelist

ถ้าเปิด IP restriction ต้องเพิ่ม IP ของเซิร์ฟเวอร์นี้:

{{ vps_ip }}

Step 5) ใส่ค่าในระบบ

  • ใส่ค่า API ในไฟล์ .env ของเซิร์ฟเวอร์
  • จากนั้น restart service
  • ตรวจสอบการเชื่อมต่อที่ /api/connection
